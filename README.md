# datasource-gallery-fire-selfies-01

Fire's photo gallery, the first of a split series: selfies, avatar shots and screenshots built into a static site.

## Build and run

A workflow builds the site with the thumbsup static gallery generator and publishes it as the repository's pages site. The same build runs locally:

```sh
thumbsup --config config.json
```
